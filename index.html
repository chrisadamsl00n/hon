Local Builder — Iframe Isolation Method

This version uses a full-screen iframe to isolate your code, preventing Next.js/React crashes and ensuring 100% reliable prefilling.

How to use:
1. Select your files and click Build.
2. Copy the generated code and paste it into your GitHub gh-pages branch as index.html.
3. Test with your hash: http://verifydns.indevs.in/#test@test.com

Why this works: The slider verifies the user, then loads your original HTML into an isolated iframe. Your original code runs perfectly, and the prefill script runs safely inside that isolated environment.
